# Dinomaly research code snapshot

This directory is a separate, code-only copy of the projects and experiment scripts in `2026_10_22_dinomaly`. It was prepared for a new GitHub repository; it is not connected to the parent drive's `PIPER_eval` repository.

It includes source code, configuration, requirements, and project documentation. Datasets, pretrained and trained weights, Python environments, run outputs, plots, and result tables are intentionally omitted. The scripts may require those external assets to run.

The `Dinomaly2` and `Cost_Filter_AD/costfilter-ad` source trees were copied without their original Git histories. Their own README and license files are retained where present. Review those projects' licenses and attribution before publishing this snapshot.

Before committing or pushing, run `git status --short` and review the staged file list with `git diff --cached --stat` and `git diff --cached --name-only`.
